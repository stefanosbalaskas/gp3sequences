# Summarise a time-varying sequence model

Summarise a time-varying sequence model

## Usage

``` r
summarise_time_varying_sequence_model(model)
```

## Arguments

- model:

  A fitted time-varying sequence model.

## Value

A list containing model metadata, parametric terms, smooth terms,
deviance explained, and convergence information.
