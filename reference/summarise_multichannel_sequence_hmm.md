# Summarise a multichannel sequence HMM

Summarise a multichannel sequence HMM

## Usage

``` r
summarise_multichannel_sequence_hmm(model)
```

## Arguments

- model:

  A fitted multichannel HMM.

## Value

A list of convergence, fit, transition, initial, and channel-specific
emission summaries.
